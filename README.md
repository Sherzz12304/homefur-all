# HomeFur All

A directory website connecting local animal shelters in Angeles City and Mabalacat City with adopters, volunteers, and donors.

## Pages
- `index.html` — Landing page
- `shelters.html` — Browse partner shelters
- `adopt.html` — Browse adoptable animals
- `volunteer.html` — Volunteer sign-up + donation info
- `partner.html` — Shelter partnership application

## Built with
- HTML5, CSS3, vanilla JavaScript
- No frameworks or backend — fully static/client-side

## Structure
├── css/
│   ├── base.css      — shared styles (header, footer, buttons, tokens)
│   ├── pages.css      — landing page styles
│   └── partner.css    — pawtner page styles
├── images/
├── script.js           — mobile menu + form handling
└── *.html
